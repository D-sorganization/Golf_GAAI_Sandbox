# E01S04 Memory Delta

## New Knowledge

### GitHub Actions Stable Versions (as of 2026-03-18)

The following action versions are confirmed stable via GitHub API:

| Action | Latest Major | Latest Tag |
|--------|-------------|-----------|
| `actions/checkout` | v6 | v6.0.2 |
| `actions/setup-python` | v6 | v6.2.0 |
| `actions/setup-node` | v6 | v6.3.0 |
| `actions/upload-artifact` | v7 | v7.0.0 |
| `actions/download-artifact` | v8 | v8.0.1 |
| `actions/cache` | v5 | v5.0.4 |
| `actions/stale` | v10 | v10.2.0 |
| `actions/github-script` | v8 | v8 |

**Note:** `actions/download-artifact` has non-linear versioning — v3.x.x variants exist alongside v4–v8. v8 is current latest.

**Verification method:** `gh api repos/actions/{action}/releases/latest --jq '.tag_name'`

## Pattern

> When writing new workflow files, default to: `checkout@v6`, `setup-python@v6`, `setup-node@v6`, `upload-artifact@v7`, `download-artifact@v8`, `cache@v5`.
