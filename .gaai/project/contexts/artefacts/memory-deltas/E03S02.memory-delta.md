# E03S02 Memory Delta

## Pattern: Notebook validation in CI/test context

When validating Jupyter notebooks programmatically (without a live kernel), execute cells in a shared namespace:
```python
ns = {}
for cell in code_cells:
    exec(''.join(cell['source']), ns)
```
Cells run in isolation (separate `exec` calls with independent namespaces) will fail when later cells reference variables from earlier cells.

## Pattern: Flat terrain floating-point tolerance

`create_flat_terrain(...).get_elevation_at(point)` may return values with small floating-point error (e.g., `5.000000000000003` for elevation=5.0). Use `abs(val - expected) < 0.01` rather than exact equality.

## Pattern: Notebook ruff compliance

For notebooks, ruff enforces:
- FURB177: Use `Path.cwd()` instead of `Path().resolve()` for current-directory lookups.
- I001: Import ordering — stdlib → blank line → third-party → blank line → local (`src.*`).
- E402: All imports before non-import statements (after `sys.path` manipulation is done via `Path.cwd()` without `sys.path` block between import groups).
