# E04S01 — Memory Delta

## New Pattern: sys.modules inspection for lazy-loading tests

When testing that a launcher module does NOT eagerly import physics engines,
use a before/after `sys.modules` snapshot approach:

```python
modules_before = set(sys.modules.keys())
import src.launchers.golf_launcher
engine_modules_added = [
    k for k in sys.modules
    if (k == "engine_pkg" or k.startswith("engine_pkg."))
    and k not in modules_before
]
assert engine_modules_added == []
```

This is more robust than checking `k not in sys.modules` absolutely,
because other tests in the session may have already imported the engine
for legitimate reasons.

## Confirmed Pattern: engine_availability guard before deferred imports

When a function-level deferred import is used, always guard with
`is_engine_available()` to get a clear error message instead of an
unguarded `ImportError`:

```python
from src.shared.python.engine_core.engine_availability import is_engine_available

def _launch_generic_mjcf(self, path):
    if not is_engine_available("mujoco"):
        raise RuntimeError("MuJoCo is not installed. Install it with: pip install mujoco")
    import mujoco  # deferred — only when needed, guarded above
```
