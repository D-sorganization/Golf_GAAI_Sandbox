## New Knowledge — Worth Persisting

### Pattern: CI `-m` flag overrides `addopts`

**Signal:** An explicit `-m` flag in a CI workflow step overrides the `addopts` global marker filter in `pyproject.toml`. If `addopts` has `-m "not live_simulation"` but the workflow step provides its own `-m "not slow and not benchmark..."`, the `addopts` marker filter is NOT applied — only the explicit flag is.

**Recommendation for conventions.md:** Add a note under Test Patterns that CI workflow `-m` flags override `addopts`. When adding a marker to `addopts`, also update all workflow steps that provide explicit `-m` flags.
