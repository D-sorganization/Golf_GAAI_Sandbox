# E02S03 — Memory Delta

## Patterns Worth Persisting

### DEFERRED Skip Annotation Pattern

When a `pytest.skip()` reason refers to pending implementation, annotate with:

```python
pytest.skip(
    "Existing skip reason"
    # TODO: Enable after <capability> is implemented — see issue #<N>
)
```

Or for `@pytest.mark.skip`:

```python
@pytest.mark.skip(
    reason="Existing reason"
    # TODO: Enable after <capability> is implemented — see issue #<N>
)
```

This creates a discoverable trail for future work without changing skip behavior.

### Skip Classification Taxonomy

Established taxonomy for this codebase:
- `VALID_OPTIONAL_DEP`: try/except ImportError guards — do NOT remove
- `VALID_PLATFORM`: CI/OS-specific — do NOT remove
- `LIVE_SIMULATION`: engine-dependent — convert to `@pytest.mark.live_simulation`
- `DEFERRED`: pending implementation — annotate with TODO + issue ref
- `STALE`: reason no longer applies — remove skip

**No stale skips found**: The codebase has been well-maintained. The 348 skip calls are predominantly legitimate VALID_OPTIONAL_DEP guards. Future Discovery stories that predict large stale-skip counts should validate this assumption before estimating scope.
