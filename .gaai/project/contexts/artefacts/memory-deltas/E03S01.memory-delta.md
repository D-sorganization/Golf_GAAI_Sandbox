# E03S01 — Memory Delta

## Durable Pattern: grep vs AST for print() detection

**Context:** Story E03S01 aimed to replace all print() calls in src/. grep returned 20 matches; AST scan found 1.

**Pattern:** When auditing code for `print()` calls, use AST (`ast.walk` + `ast.Call`) rather than grep. grep will match print() inside docstrings, Example: blocks, and f-string code templates. AST only finds live callable invocations.

**Suggested addition to conventions.md:**
> **Auditing print() usage:** Use AST scan (`ast.parse` + `ast.walk`) not grep for authoritative detection. grep will produce false positives from docstring Example blocks and f-string code templates.
