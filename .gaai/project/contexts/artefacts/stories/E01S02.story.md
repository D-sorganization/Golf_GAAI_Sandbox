# E01S02 — Remove Stray Debug Files and Update .gitignore

## Context

The repository root contains numerous debug output files, runtime logs, and build artifacts that should never be tracked in git. These pollute the root, confuse contributors, and some are large binary/generated files.

## Acceptance Criteria

- [ ] The following files are deleted from the repo (if they exist):
  - `REVIEW_SUMMARY.txt`
  - `full_collect.txt`
  - `line_run.txt`
  - `open_issues.txt`
  - `pytest_collect_out.txt`
  - `timeout_test.txt`
  - `backend.log`
  - `launcher_debug.log`
  - `launcher_debug_02.log`
  - `coverage.xml`
  - `golf_modeling_suite.db`
  - `out.txt`
  - `err.log`
- [ ] The following review `.md` files are moved to `docs/` or deleted if superseded:
  - `BUILD_INFRASTRUCTURE_REVIEW.md`
  - `CONFIG_ISSUES_QUICK_REFERENCE.md`
  - `INFRASTRUCTURE_REVIEW_INDEX.md`
- [ ] `.gitignore` updated to prevent recurrence, adding patterns:
  ```
  *.log
  *_collect.txt
  *_run.txt
  *_out.txt
  *_test.txt
  out.txt
  err.log
  coverage.xml
  htmlcov/
  *.db
  REVIEW_SUMMARY.txt
  open_issues.txt
  ```
- [ ] `git status` shows no untracked files matching these patterns
- [ ] CI passes after changes

## Implementation Notes

- Check each file exists before deleting with `ls` — don't fail if already absent
- For the `.md` review files: check if content is still relevant; move to `docs/` if so
- Do NOT delete `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `AGENTS.md`, `CHANGELOG.md`

## Scope

Housekeeping only. No code changes, no functional impact.
