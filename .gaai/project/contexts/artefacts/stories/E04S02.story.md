# E04S02 — Pinocchio Engine Parity

## Context

Pinocchio is the third physics engine in the tri-engine validation strategy. MuJoCo and Drake have full feature/diagnostic parity (screw kinematics, power-flow diagnostics, contact modeling). Pinocchio must match them to enable cross-engine consistency tests to pass end-to-end.

## Dependencies

- E02S01 must be complete (`live_simulation` marker must exist)

## Acceptance Criteria

- [ ] **TDD first:** Failing parity tests written before any implementation:
  - `tests/engines/pinocchio/test_pinocchio_parity.py` with tests matching MuJoCo/Drake diagnostic outputs
  - Tests must cover: forward kinematics, inverse kinematics, Jacobian computation, screw axis kinematics, contact forces (if supported)
- [ ] All parity tests pass after implementation
- [ ] Pinocchio engine adapter implements the same interface/protocol as MuJoCo and Drake adapters
- [ ] Any shared computation logic extracted to `src/shared/python/physics/` (DRY)
- [ ] DbC precondition checks added at the Pinocchio adapter boundary (input validation with descriptive error messages)
- [ ] Cross-engine consistency tests (`tests/` pattern: `test_*_cross_engine*`) pass with Pinocchio included
- [ ] `ruff check` and `mypy` pass on all modified files
- [ ] No new `type: ignore` comments introduced
- [ ] No `print()` calls — use logging

## Implementation Notes

- Start by reading `src/engines/physics_engines/mujoco/` and `src/engines/physics_engines/drake/` adapter implementations to understand the expected interface
- The shared protocol/interface class (if it exists) is in `src/shared/python/physics/` — implement to it
- Use `@pytest.mark.live_simulation` on all Pinocchio-specific tests that require pinocchio installed
- Check what `compute_affine_drift` and `get_sensors` should return by looking at MuJoCo/Drake equivalents
- Reference: the current `feat/pinocchio-parity-fixes` branch has partial work — review it before starting

## Scope

- `src/engines/physics_engines/pinocchio/` — primary implementation
- `src/shared/python/physics/` — extract shared logic here (DRY)
- `tests/engines/pinocchio/` — parity tests
