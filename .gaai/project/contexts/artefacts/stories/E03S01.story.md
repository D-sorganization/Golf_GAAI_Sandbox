# E03S01 — Replace print() with Logging

## Context

109 `print()` calls exist in source code (`src/`), violating the AGENTS.md standard that mandates the `logging` module. This story systematically converts them.

## Acceptance Criteria

- [ ] All `print()` calls in `src/` replaced with appropriate `logging` calls:
  - Debug/trace output → `logger.debug(...)`
  - Informational status → `logger.info(...)`
  - Warnings → `logger.warning(...)`
  - Errors → `logger.error(...)`
- [ ] Each converted file imports `import logging` and has `logger = logging.getLogger(__name__)` at module level
- [ ] Net `print()` count in `src/` reduced to 0
- [ ] Tests in `tests/` are exempt (print in tests is acceptable)
- [ ] `examples/` scripts: convert to logging if they import src modules; may keep print for pure notebook/tutorial output
- [ ] All existing tests continue to pass
- [ ] `ruff check src` passes after changes

## Implementation Notes

- Enumerate: `grep -rn "^\s*print(" src/ --include="*.py"`
- Use `get_logger` from `src/shared/python/logging_pkg/logging_config.py` if available, otherwise use `logging.getLogger(__name__)`
- Common patterns to convert:
  - `print(f"Error: {e}")` → `logger.error("Error: %s", e)`
  - `print("Starting...")` → `logger.info("Starting...")`
  - `print(f"Debug: {var}")` → `logger.debug("Debug: %s", var)`
- Do NOT convert `print()` in Jupyter notebooks (`.ipynb`) — those are intentional output

## Scope

Source code only. No logic changes — only output mechanism changes.
