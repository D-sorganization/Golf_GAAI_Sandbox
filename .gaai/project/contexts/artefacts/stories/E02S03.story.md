# E02S03 — Audit pytest.skip Calls

## Context

310 `pytest.skip()` calls exist in the test suite. Many may be legitimately guarding optional dependencies, but others may be masking tests that should actually run. This story systematically audits and reclassifies the skip calls.

## Dependencies

- E02S01 must be complete (`live_simulation` marker must exist)

## Acceptance Criteria

- [ ] All `pytest.skip()` and `pytest.mark.skip` calls in `tests/` catalogued in a report at `docs/testing/skip-audit.md`
- [ ] Each skip classified as one of:
  - `VALID_OPTIONAL_DEP`: skip is correct guard for optional engine (keep as-is or convert to `pytest.importorskip`)
  - `VALID_PLATFORM`: platform-specific (Windows/Linux/macOS) — keep as-is
  - `LIVE_SIMULATION`: test can run with engine available → convert to `@pytest.mark.live_simulation`
  - `DEFERRED`: test is disabled pending implementation → add `TODO:` comment with issue reference
  - `STALE`: test skipped for a reason that no longer applies → remove skip and enable test
- [ ] At least 20 skips reclassified and updated in code
- [ ] Net reduction in unconditional `pytest.skip()` calls (target: reduce by at least 20)
- [ ] All modified tests pass (or are properly marked)
- [ ] `docs/testing/skip-audit.md` committed with findings summary

## Implementation Notes

- Focus first on `STALE` skips — easiest wins
- Use: `grep -rn "pytest.skip\|pytest.mark.skip" tests/` to enumerate
- For `LIVE_SIMULATION` conversions: add `@pytest.mark.live_simulation` AND keep any `importorskip` guard
- Do NOT remove legitimately guarding skips for engines that aren't installed in CI
