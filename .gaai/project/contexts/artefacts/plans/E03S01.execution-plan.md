## Implementation Plan

### Step 1: Modify addPrescribedMotion.py

1. Add `import logging` at module top (after existing comment block)
2. Add `logger = logging.getLogger(__name__)` after import
3. Replace `print("ERROR: Need to load a model first!\\n")` with `logger.error("Need to load a model first!")`

**Note:** This file is a vendored Stanford/Apache-2.0 OpenSim tutorial script. It is a script (not a module meant for import), but since it's inside `src/` and the AC is explicit, we comply. The conversion is minimal and does not break the tutorial flow — `logging` is part of the Python standard library and available in any Python environment.

### Step 2: QA Verification

2. Run `ruff check src` to verify no lint regressions
